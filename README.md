# homework_python

## Описание базового синтаксиса записи и форматирования

Проект использует следующие технологии и синтаксис:

1. **Python**: Основной язык программирования для написания тестов.
2. **Selenium**: Библиотека для автоматизации взаимодействия с веб-браузером.
3. **Pytest**: Фреймворк для написания и запуска тестов.
4. **Allure**: Инструмент для генерации отчетов о выполнении тестов.

### Форматирование кода

- Код форматируется в соответствии с PEP 8 (стиль написания кода на Python).
- Для проверки соотвествия кода стандартам используется Flake8.
- Для документирования методов и функций используются docstrings.
- Шаги теста размечаются с помощью `@allure.step` или `with allure.step` для улучшения читаемости отчетов.

---

## Инструкция по запуску тестов для формирования отчета Allure

1. Установите необходимые зависимости:
   ```bash
   pip install -r requirements.txt
   ```

2. Запустите тесты с генерацией отчета Allure:
   ```bash
   pytest lesson_10 --alluredir=lesson_10/allure-results
   ```

   Эта команда запустит все тесты из директории lesson_10 и 
   сохранит результаты в директорию `lesson_10/allure-results`.

---

## Инструкция по просмотру сформированного отчета Allure

1. После завершения тестов, чтобы просмотреть отчет, выполните команду:
   ```bash
   allure serve lesson_10/allure-results
   ```

   Эта команда запустит локальный сервер и откроет отчет в браузере.

2. В отчете Allure вы увидите:
   - **Название теста**: Например, `Тестирование онлайн-магазина`.
   - **Описание теста**: Описание, что тест проверяет основные сценарии работы онлайн-магазина.
   - **Шаги теста**:
     - Открытие страницы онлай-магазина.
     - Добавление товара.
     - Открытие корзины.
     - Получение списка товаров в корзине.
     - Проверка списка товаров в корзине.
     - Нажатие кнопки Checkout.
     - Ввод данных пользователя.
     - Нажатие кнопки Continue.
     - Получение итоговой суммы заказа.
     - Проверка итоговой суммы заказа.
   - **Результат**: Успешное выполнение или ошибка.
